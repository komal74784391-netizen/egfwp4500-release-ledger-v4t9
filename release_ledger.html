This ledger is maintained by the lab release committee and is the authoritative record of public-release clearance for software accompanying lab publications. Authors must consult this page before adding any code link to a public website.

Policy: only projects whose status code is CLEARED may be linked from the public website. Projects with status EMBARGOED, PENDING, or NO_PUBLIC_REPOSITORY must not be linked.
